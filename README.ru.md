Пользовательский скрипт для магазина Steam, который восстанавливает **заблокированные страницы товаров** и добавляет необязательный **гостевой поиск** — анонимные поисковые подсказки в шапке и включаемую отдельно гостевую страницу `/search`, без cookies аккаунта.

Скрипт повторно запрашивает URL приложений **без cookies аккаунта** (гостевой просмотр), переносит настоящую вёрстку магазина в текущий документ и восстанавливает элементы вишлиста, подписки и игнорирования для авторизованных пользователей после переноса. **Гостевые поисковые подсказки** включены по умолчанию; полный гостевой режим **страницы `/search`** выключен по умолчанию (включается в Region Bypass → Поиск). Для блокировок по IP необязательный **proxy gateway** можно настроить в панели в стиле Steam (меню аккаунта → Настройки Region Bypass).

Совместим с [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/), [Greasemonkey](https://www.greasespot.net/), ScriptCat и другими менеджерами, поддерживающими блок метаданных `// ==UserScript==`.

## Обновления

Скрипт содержит метаданные `@updateURL` и `@downloadURL`, указывающие на прямой файл GitHub. Поддерживаемые менеджеры проверяют обновления автоматически (Tampermonkey: панель управления → интервал проверки; Violentmonkey: аналогично).

**Чтобы выпустить новую версию:**

1. Измените `version` в `package.json` (SemVer).
2. Выполните `npm run build` (обновляет корневые `.user.js` / `.meta.js`).
3. Добавьте запись в [`CHANGELOG.md`](CHANGELOG.md).
4. Отправьте изменения в `main` (или создайте GitHub Release).

Менеджеры сравнивают установленный `@version` с удалёнными метаданными и решают, предлагать ли обновление. Полный процесс описан в [DEVELOPMENT.md](DEVELOPMENT.md).

## Возможности

- **Инъекция с приоритетом переноса** — заменяет гостевую вёрстку игры в живом `#responsive_page_template_content`, сохраняя шапку авторизованного пользователя, глобальные переменные сессии, загруженные стили и скрипты; `document.write` остаётся резервным вариантом полной перезаписи
- **Восстановление очереди для авторизованных** — пересоздаёт элементы вишлиста, подписки и игнорирования после переноса и отправляет действия через живую сессию
- **Автопропуск или кнопка** — срабатывает сразу на заблокированных страницах или сначала показывает предложение вручную
- **Анонимный запрос** — использует `GM_xmlhttpRequest` с `anonymous: true` (без cookies входа)
- **Язык магазина** — гостевой запрос использует `Steam_Language`, `?l=` и `Accept-Language`, чтобы страница соответствовала языку интерфейса Steam
- **Cookies возрастного шлюза** — отправляет cookies `birthtime` / mature-content, чтобы гостевые страницы реже останавливались на проверке возраста
- **Необязательная страна магазина (`cc`)** — переопределяет страну магазина Steam для гостевого запроса
- **Панель proxy gateway** — включение/выключение, хост, порт, логин, пароль, режим URL
- **Главный переключатель региона + управление баннером** — отключает обход страниц, не затрагивая гостевой поиск; при необходимости скрывает региональный баннер
- **Интерфейс в стиле Steam** — вход в настройки в меню аккаунта (`#account_dropdown`, в стиле SteamDB); резервная кнопка для неавторизованных в `#global_actions`; панель со списком на главной и вкладками Основные / Поиск / Кэш / Прокси / О скрипте, редактированием черновика, кнопками Сброс, Отмена, Сохранить и Сохранить и перезагрузить
- **Локализованный интерфейс** — панель и сообщения на en, ru, zh-CN, es, pt-BR, de, fr, ja, ko, pl; выбор языка интерфейса с автоопределением браузера
- **Ручное управление** — перезагрузка внедрённого контента, открытие настроек из баннера или меню менеджера скриптов
- **Гостевые поисковые подсказки** — включены по умолчанию: анонимный список подсказок через тот же стек гостевых запросов (прокси / `cc` / кэш); отключаются в **Region Bypass → Поиск**
- **Гостевая страница `/search`** — включается отдельно: анонимный повторный запрос и внедрение для `store.steampowered.com/search` (тот же стек); включается в **Region Bypass → Поиск**
- **Вкладка «Кэш»** — индикатор использования, TTL и максимум записей, выбор типов гостевых страниц для хранения, просмотр и удаление кэшированного HTML, просмотр и очистка списка заблокированных игр
- **Реестр заблокированных игр** — запоминает ID приложений с региональной блокировкой (переключатели на вкладке «Поиск») и подсвечивает их в гостевом поиске; список и очистка — на вкладке **Кэш**

## Поддерживаемые страницы

| Сайт | Шаблон URL | Примечания |
|------|-------------|-------|
| Магазин Steam (приложения) | `https://store.steampowered.com/app/{id}/…` | Обход региональной ошибки (основной сценарий) |
| Магазин Steam (поиск) | Поиск в шапке + `https://store.steampowered.com/search/?term=…` | **Гостевые поисковые подсказки** и необязательная **гостевая страница /search** в Region Bypass → Поиск |

Страницы приложений работают, когда Steam показывает **«This item is currently unavailable in your region»** (сообщение о недоступности в вашем регионе) — например, **Call of Duty: Modern Warfare 4** в ограниченных регионах. **Гостевые поисковые подсказки** включены по умолчанию для строки поиска в шапке. Гостевой повторный запрос для полной страницы `/search` **выключен по умолчанию** (тот же стек анонимных гостевых запросов: прокси / `cc` / кэш) — включите его в **Region Bypass → Поиск**. Сохранённые ID заблокированных приложений можно подсвечивать в результатах поиска.

```

       ▼
#error_box / Oops совпадает с «unavailable in your region»?
       │
       ├── нет ──► ожидание (кнопка настроек доступна)
       │
       └── да ──► Формирование целевого URL (?l= язык, опционально ?cc=)
                │
                ▼
       Есть кэш (в пределах TTL)? ── да ──► использовать сохранённый гостевой HTML
                │ нет
                ▼
       Опционально: переписать URL через proxy gateway
                │
                ▼
       GM_xmlhttpRequest(anonymous: true,
         Cookie: birthtime…; Steam_Language=…)
                │
                ▼
       Разбор HTML → извлечь .game_page_background / #tabletGrid
                │
                ├── всё ещё заблокировано? ──► показать ошибку + предложить прокси
                │
                ├── перенос в живую оболочку
                │   ├── синхронизировать title, классы, стили, скрипты
                │   ├── восстановить элементы очереди авторизованного пользователя
                │   └── сбой → резервный document.write(гостевой HTML)
                │
                └── баннер + повторный запуск функций (успешный HTML сохранён в кэш)
```

### Гостевой поиск

В панели Region Bypass (**вкладка «Поиск»**):

1. **Гостевые поисковые подсказки** (включены по умолчанию) — при вводе в поиске шапки магазина анонимно запрашиваются подсказки из `/search/results` (до 25 игр), дополняемые данными `/api/storesearch/`, когда они доступны (резервный вариант: `/search/suggest`).
2. **Гостевая страница `/search`** (выключена по умолчанию) — отправка поиска или открытие `/search/?term=…` может повторно запросить результаты как гость и внедрить их на страницу, если этот параметр включён.
3. Необязательный **реестр заблокированных игр** подсвечивает приложения, которые вы ранее открывали на странице с региональной ошибкой.
4. **Автоопределение блокировок в поиске** (включено по умолчанию) проверяет каждый результат с вашими cookies авторизованной сессии Steam и добавляет регионально заблокированные приложения в список (индикатор прогресса + загрузчики для каждого элемента; область и параллелизм настраиваются).

Использует те же настройки прокси, `cc`, языка и кэша, что и обход страниц приложений.

### Анонимный запрос

Steam часто ограничивает страницу магазина по **стране аккаунта**. Привилегированный запрос без cookies сессии может вернуть публичную вёрстку магазина для этого IP. Скрипт никогда не использует вашу авторизованную сессию для запроса обхода.

### Язык магазина

Гостевой запрос по возможности повторяет язык магазина Steam:

1. Cookie `Steam_Language` с текущей страницы
2. Иначе язык, производный от локали интерфейса/браузера
3. Применяется как `?l=…`, `Cookie: Steam_Language=…` и `Accept-Language`

### Proxy gateway

Менеджеры пользовательских скриптов **не могут** привязать системный SOCKS/HTTP-прокси к `GM_xmlhttpRequest`. Если блокировка основана на IP, укажите в панели локальный или удалённый **HTTP-шлюз**, который загружает URL Steam из другой сети.

| Режим | Пример запроса |
|------|-----------------|
| `host:port/https://…` | `http://127.0.0.1:8765/https://store.steampowered.com/app/412020/` |
| `host:port/store.steampowered.com/…` | `http://127.0.0.1:8765/store.steampowered.com/app/412020/` |
| `host:port/?url=…` | `http://127.0.0.1:8765/?url=https%3A%2F%2Fstore.steampowered.com%2Fapp%2F412020%2F` |

В этом репозитории есть необязательный Node-шлюз: [`proxy-gateway.mjs`](proxy-gateway.mjs).

```bash
npm install
npm run gateway

# with upstream SOCKS/HTTP:
# UPSTREAM_PROXY=socks5://user:pass@host:1080 npm run gateway
```

Затем в панели скрипта: Host `127.0.0.1`, Port `8765`, режим `host:port/https://…`, прокси **ВКЛ**.

## Метаданные скрипта

Ключевые поля `// ==UserScript==`, используемые менеджерами:

| Поле | Значение |
|-------|-------|
| `@namespace` | `https://github.com/NemoKing1210/steam-region-block-bypass` |
| `@version` | Семантическая версия (должна повышаться при каждом релизе) |
| `@updateURL` / `@downloadURL` | Прямой GitHub URL файла `steam-region-block-bypass.user.js` |
| `@homepageURL` | Этот репозиторий |
| `@supportURL` | GitHub Issues |
| `@license` | MIT |
| `@grant` | `GM_xmlhttpRequest`, `GM_getValue`, `GM_setValue`, `GM_addStyle`, `GM_registerMenuCommand` |
| `@connect` | `store.steampowered.com`, `*` (пользовательские proxy gateway) |

Локализованные теги `@name` и `@description` предоставлены для en, ru, zh-CN, es, pt-BR, de, fr, ja, ko и pl.

## Необходимые разрешения

| Разрешение | Назначение |
|-------|---------|
| `GM_xmlhttpRequest` | Загрузка страницы магазина без cookies страницы / ограничений CORS |
| `GM_getValue` / `GM_setValue` | Сохранение настроек прокси и интерфейса |
| `GM_addStyle` | Внедрение CSS панели и баннера в стиле Steam |
| `GM_registerMenuCommand` | Открытие настроек из меню менеджера скриптов |

`@connect *` требуется, чтобы скрипт мог обращаться к настроенному пользователем хосту proxy gateway.

## Разработка

Собран на **Vite** + **vite-plugin-monkey**. Редактируйте ESM-модули в [`src/`](src/), затем выполните `npm run build`, чтобы обновить закоммиченные установочные артефакты. Подробности: [DEVELOPMENT.md](DEVELOPMENT.md), [CONTRIBUTING.md](CONTRIBUTING.md).

```bash
npm install
npm run dev      # живой userscript "dev:" через Vite
npm run build    # production → dist/ + корневые .user.js / .meta.js
npm test         # юнит-тесты на встроенном Node test runner
npm run ci       # тесты + сборка + проверка артефактов
npm run gateway  # необязательный локальный proxy gateway
```

### Локальный рабочий процесс (Violentmonkey)

1. Клонируйте этот репозиторий и выполните `npm run build`.
2. В Violentmonkey установите скрипт из локального корневого `steam-region-block-bypass.user.js`.
3. Включите **Отслеживать локальный файл** перед закрытием диалога установки.
4. Редактируйте `src/`, пересобирайте, перезагружайте страницу Steam — или используйте `npm run dev` для HMR.

### Локальный рабочий процесс (Tampermonkey)

Tampermonkey не отслеживает локальные файлы из коробки. Варианты:

- Используйте `npm run dev` и установите выдаваемый userscript `dev:`, либо
- Переустанавливайте из собранного файла / URL после каждого `npm run build`, либо
- Временно укажите `@updateURL` / `@downloadURL` на `http://localhost:...` во время разработки (не коммитьте локальные URL).

### Настройки

Настройки хранятся в хранилище userscript (`srbb_settings_v2`; плоский объект `srbb_settings` v1 мигрируется один раз и остаётся нетронутым для отката) через панель настроек:

| Настройка | По умолчанию | Описание |
|---------|---------|-------------|
| Язык интерфейса | Авто | Язык панели / сообщений; `Авто` следует за браузером. Cookie языка магазина Steam по-прежнему имеет приоритет для гостевых запросов |
| Включить обход региона | вкл | Управляет обнаружением страниц, авто/ручным режимом, баннером, кнопкой на других сайтах и восстановлением очереди. У гостевого поиска свои переключатели |
| Триггер обхода | Авто | **Авто** срабатывает на страницах с региональной ошибкой; **Показать кнопку** ждёт ручного подтверждения |
| Показывать баннер | вкл | Показывать уведомление о регионе над обойдённой страницей |
| Страна магазина (`cc`) | пусто | Необязательный код страны Steam для гостевых запросов |
| Показывать toast-уведомления | вкл | Всплывающие уведомления в стиле Steam об изменениях настроек; можно отключить |
| Позиция toast | Сверху справа | Угол для toast-уведомлений: верх/низ × лево/право |
| Гостевые поисковые подсказки | вкл | Вкладка **Поиск**: анонимные подсказки в шапке |
| Гостевая страница `/search` | выкл | Вкладка **Поиск**: заменить живые результаты анонимным гостевым запросом |
| Запоминать заблокированные игры | вкл | Вкладка **Поиск**: сохранять ID приложений, когда Steam показывает региональную ошибку |
| Подсвечивать заблокированные в поиске | вкл | Вкладка **Поиск**: помечать сохранённые игры в гостевых результатах |
| Автоопределение блокировок в поиске | вкл | Вкладка **Поиск**: проверять страницы результатов с авторизованной сессией; область и параллелизм настраиваются |
| Длительность кэша (минуты) | `60` | Вкладка **Кэш**: повторно использовать успешную гостевую страницу столько времени; `0` отключает кэш. Кнопка **Обновить** в баннере всегда загружает свежие данные |
| Макс. страниц в кэше | `30` | Вкладка **Кэш**: хранить самые новые записи гостевого HTML (мягкий бюджет индикатора — 10 МБ) |
| Кэшировать страницы приложений / поиска | вкл / вкл | Вкладка **Кэш**: какие типы гостевого HTML хранить; выключение останавливает запись и удаляет этот тип |
| Использовать proxy gateway | выкл | Направлять анонимный запрос через шлюз |
| Режим шлюза | `gateway` | Как целевой URL добавляется к `host:port` |
| Хост / Порт | пусто | Адрес шлюза (например, `127.0.0.1` / `8765`) |
| Логин / Пароль | пусто | Необязательная HTTP Basic-аутентификация для шлюза |

Настройки записываются в `srbb_settings_v2`. Кэш страниц сохраняет существующий ключ `srbb_page_cache`, а реестр заблокированных — `srbb_blocked_apps`.
